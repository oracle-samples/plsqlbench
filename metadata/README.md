# Spider2 Metadata

These optional annotation files correspond exactly to the released Spider2 dev
dataset rows. They support difficulty and reasoning-type analysis and are not
required for execution. Multi-turn metadata includes conversation and turn
fields matching `datasets/spider2_mt/spider2_mt.jsonl`.
